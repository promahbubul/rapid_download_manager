Rapid Download Manager

Official Public Privacy Policy

✓ 100% Zero-Telemetry Certified ✓ Pure Local Storage Only

Effective Date: September 2026 | Version 1.0.0

1. Fundamental Privacy Commitment

At Rapid Download Manager, we believe that your downloads, file transfers, and browsing activities belong solely to you. We hold a strict zero-telemetry policy:

Rapid Download Manager does not collect, record, track, transmit, or monetize any personally identifiable information (PII), download activity, or user diagnostics.

2. Information We DO NOT Collect

  • No Personal Identifiers: We do not ask for or collect your name, email address, physical location, or credentials.
  • No Download URL or File Tracking: The URLs you download, file contents, file names, and download metadata are processed entirely in local memory on your device. Nothing is sent to any remote server.
  • No Analytics or Tracking SDKs: The software contains zero analytics libraries, zero advertising frameworks, and zero tracking beacons.
  • No Account System: Rapid Download Manager operates as completely standalone software without requiring any login or account creation.
  • No Background Telemetry: No usage metrics or behavioral tracking are performed in the background.

3. Local Storage Architecture

All application state, user preferences, download history, and schedules are stored exclusively on your local computer in standard Windows user directories:

  • %APPDATA%\RapidDownloadManager\history.json — Download history and resume points.
  • %APPDATA%\RapidDownloadManager\config.json — User settings and speed limiter configurations.
  • %APPDATA%\RapidDownloadManager\scheduler.json — Scheduled start/stop timers.
  • %LOCALAPPDATA%\RapidDownloadManager\logs\app.log — Local diagnostic logs.

This data remains strictly on your hard drive and can be purged at any time from within the application or by running the uninstaller.

4. Automatic Sensitive Data Sanitization

Rapid Download Manager includes a built-in zero-leak credential sanitizer in its logging engine. If a download URL contains sensitive query parameters such as token=, api_key=, or password=, the logger automatically strips and redacts them to [REDACTED] before any diagnostic information is written to local log files.

5. Network Communications

Rapid Download Manager communicates over the network exclusively under two circumstances:

  1. User-Initiated Downloads: Connecting to the destination servers for URLs that you explicitly add or import from your web browser.
  2. Update Verification: Connecting to the official GitHub API (api.github.com) only when you manually check for updates or open the About modal to verify the latest release tag.

All network traffic uses memory-safe Rustls TLS encryption.

6. Crash Diagnostics

In the unlikely event of an unexpected crash, diagnostic backtraces and version information are written locally to %LOCALAPPDATA%\RapidDownloadManager\logs\crash.log. These crash logs are never uploaded automatically over the internet.
